# 羽球場地搶訂

在台北市運動中心開放預約的那一刻（每天午夜 00:00），自動幫你搶場地的小程式。
你只要先設定好帳密、場地、時段，按下「開始」，然後讓電腦開著就好。

目前支援：**中正運動中心**（羽球 7-1 ～ 7-5 五片場地）。中山運動中心暫時停止。

---

## 使用說明（給球友）

### 使用前請先了解

- **帳號風險**：這是非官方的自動預約程式。預約網站若認定使用自動程式或請求異常，
  有可能停權你的會員帳號；是否使用請自行判斷。
- **可能突然失效**：預約網站已在按鈕前加上人機驗證（Cloudflare Turnstile），本程式不處理也不繞過它。
  網站一旦開始強制驗證，程式就會整個失效，結果會顯示為失敗或 ⚠️。
- **帳密只用來登入官方網站**：程式不會儲存或傳送你的帳密到其他地方，每次開啟都要重新輸入。
- **建議用自己家裡或手機熱點的網路**，避免在不信任的公共 Wi-Fi 上執行。

### 1. 下載

到 [Release 頁面](https://github.com/Ta-Wei-Liao/badminton_bot/releases) 下載最新版本：

- Mac（Apple 晶片）：`BadmintonBot-macOS.zip`
- Windows：`BadmintonBot-Windows.zip`

**請只從這個頁面下載**，不要執行別人轉傳的版本：程式沒有簽章，系統分辨不出被動過手腳的檔案。
每個 zip 旁都有一個 `.sha256` 檢查碼檔，對檔案有疑慮時可以請作者幫忙比對。

### 2. 解壓縮

- Mac：雙擊 zip，會得到 `BadmintonBot.app`，可以拖到「應用程式」資料夾。
- Windows：對 zip 按右鍵 →「全部解壓縮」，會得到 `BadmintonBot` 資料夾，裡面有 `BadmintonBot.exe`。
  請先解壓縮再執行，不要直接在 zip 裡面開。

<!-- 截圖：解壓縮後的檔案 -->

### 3. 先確認電腦有裝 Google Chrome

程式登入網站要靠 Chrome。沒有的話請先到 <https://www.google.com/chrome/> 安裝。
第一次執行需要網路（會自動下載 Chrome 的驅動程式）。

按下「開始」時程式會先檢查一次 Chrome 能不能用；有問題會馬上用中文告訴你，
不會等到開搶才發現。

### 4. 第一次開啟：放行（因為程式沒有簽章，系統一定會擋）

**Mac**

1. 雙擊 `BadmintonBot.app`，會出現「無法確認開發者」之類的訊息，先按「完成」或「好」。
2. 打開「系統設定 → 隱私權與安全性」，往下捲到「安全性」區塊。
3. 找到 BadmintonBot 被擋的提示，按「強制打開」（或「仍要打開」），輸入電腦密碼。
4. 之後就可以正常開啟了。

<!-- 截圖：Mac 隱私權與安全性的「強制打開」按鈕 -->

**Windows**

1. 雙擊 `BadmintonBot.exe`，會出現藍色的「Windows 已保護您的電腦」。
2. 按「其他資訊」。
3. 按「仍要執行」。

<!-- 截圖：Windows SmartScreen 的「其他資訊」與「仍要執行」 -->

### 5. 設定並開始

<!-- 截圖：主視窗表單 -->

1. 選運動中心。
2. 填身分證字號與密碼（就是運動中心網站的會員帳密；只用來登入，不會存到任何檔案）。
3. 勾選要搶的**場地**和**時段**（06:00–07:00 一直到 21:00–22:00）。
4. 視窗下方會顯示「已選 N 片 × M 時段 ＝ K 個請求（上限 12）」，
   以及「將於 ○/○（○）00:00 開搶，預約 ○/○（○）的場地」。
   - 場地數 × 時段數**不能超過 12**，超過就沒辦法開始，請減少勾選。
   - 開搶時間是「按下開始後的下一個台北時間午夜 00:00」；預約的是開搶日起算 7 天後那一天。
   - 如果顯示「距離開搶太近，校時可能不準」，代表離午夜不到 4 分鐘，程式仍會跑，但搶到的機率會下降。
5. 按「開始」。按下後表單會鎖住，視窗會顯示目前階段和倒數。開搶前可以按「取消」；請求一旦送出就無法取消。

### 6. 執行期間：插電、不要闔蓋

- 電腦請**插著電**，並且**不要闔上螢幕**，也不要關掉程式視窗。程式會盡量避免電腦進入睡眠，但闔蓋仍然可能中斷。
- 程式會在開搶前約 3 分鐘才登入，所以按下開始後不需要一直盯著，但請讓它保持開啟直到出現結果。
- 開搶前最後幾十秒請不要操作視窗。

### 7. 怎麼看結果

<!-- 截圖：結果表 -->

結束後視窗會出現一張表，橫軸是時段、縱軸是場地，每一格是：

- ✅ 搶到了
- ❌ 沒搶到（被別人搶走，或網站回應失敗）
- ⚠️ 無法判斷（網站回了非預期的內容）

底下會顯示「搶到 X / Y 格」。**不論結果如何，請再自己登入運動中心網站確認一次預約紀錄**，
以網站上的為準。

### 8. Log 檔與出事時怎麼辦

每次執行都會留下一個 log 檔，位置在：

- `文件/badminton_bot_logs`（Windows 與 Mac 都是使用者資料夾下的 `Documents/badminton_bot_logs`）
- 如果系統不讓程式寫入「文件」資料夾，會改存在使用者資料夾下的 `badminton_bot_logs`，
  再不行就存到系統暫存資料夾；實際位置會寫在視窗的訊息裡，結果畫面也會顯示

結果畫面也有「打開 log 資料夾」按鈕。log 檔**不會**包含你的密碼，
但會有預約網站顯示的姓名（中間一字遮住，例如「王○明」）和你搶的場地時段。

如果程式出現錯誤、沒搶到但你覺得不對勁，或視窗卡住：
**請把該次的 log 檔（檔名是日期時間）傳給作者**，並告訴作者視窗標題上的版本號（例如 `v1.0.0`）。

### 常見問題

- **按開始就跳出 Chrome 相關錯誤**：確認有安裝 Google Chrome 並且連得上網路。
- **能保證搶到嗎？** 不能。這是和其他人比速度，程式只是盡量幫你準時、同時送出請求。
- **請不要**反覆開關程式、重複按開始來測試，頻繁登入預約網站可能導致帳號被停權。

## 開發者說明

給想改程式的人，詳細的架構、時序設計與慣例請見 [CLAUDE.md](CLAUDE.md)。

```bash
pyenv activate badminton_bot
pip install -r requirements.txt
python -m badminton_bot.main      # 開啟視窗
pytest                            # 全部離線測試
./bundling_scripts.sh             # 本機打包成 dist/BadmintonBot.app
```

發佈：先把 `badminton_bot/__init__.py` 的 `__version__` 改成新版號，再推送同名的 `v*` 標籤
（例如 `git tag v1.0.0 && git push origin v1.0.0`），兩者不一致時 GitHub Actions 會直接失敗；
一致的話會在 macOS 與 Windows 上建置並把 zip 上傳到 Release。
